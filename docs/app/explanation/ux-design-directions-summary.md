# UX Design Directions Summary

Brief summary: Pointer to the canonical UX design directions artifact, with a concise overview of the six directions and the chosen baseline.

## When to use this doc

Use this summary when evaluating UI changes against the agreed direction, or when reviewing the directions artifact.

## Design directions (concise overview)

1. **Calm Minimal**: light surfaces, crisp dividers, progress/resume emphasis, compact lists, tonal blue primary, amber warnings.
2. **Balanced Calm (Recommended)**: Material 3 + AppTokens, gentle banner gradients, resume/import card near top, chips for match/breakdown state, clear scope tabs.
3. **Finance Crisp**: higher contrast, bold money colors, strong headers, progress with percent labels, guarded deletes emphasized.
4. **Soft Tonal**: softer surfaces and rounded cards, tonal buttons, prominent helper banners, emoji-forward category lists.
5. **Dashboard Dense**: higher information density, tighter tables/lists, status chips, inline tooltips for scope hints.
6. **Card-forward**: card stacks with previews, progress/match pills on cards, single primary CTA per card.

## Chosen baseline: Balanced Calm

Balanced Calm is the baseline direction because it aligns with Material 3 + AppTokens, supports the desired calm/confident emotional tone, and keeps resume/import prominence with shallow navigation and clear scope cues.
