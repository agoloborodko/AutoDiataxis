# Asset Inventory

Brief summary: Current asset inventory status and how to record future assets.

## When to use this doc

Use this doc when adding new assets, auditing asset usage, or updating `pubspec.yaml`.

## Current inventory

- No app assets are declared in `pubspec.yaml` (no `assets:` section).

## Adding assets

- Store assets under `assets/<type>/`.
- Declare the asset paths in `pubspec.yaml` when assets are introduced.
- Record new assets here with path, type, and usage notes.
