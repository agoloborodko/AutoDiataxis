# Record documentation updates per change

A meaningful documentation change is now one file under [/docs/updates/](/docs/updates/). [/docs/updates.md](/docs/updates.md) keeps earlier entries and no longer receives new dated entries. A file in [/docs/updates/](/docs/updates/) does not get a parent-index line. A new factual reference area is its own file.
